# FlySoar / Henry Langmack outreach package

Use this folder as a practical outreach kit, not as a single giant document to send.

## Recommended order of use

1. **Read first:** `flysoar_dossier.md` → start with “Quick cheat sheet,” “What to say to Henry,” and “First-contact message variants.”
2. **Send first:** `first_contact_messages.md` → use the X/DM version unless email/LinkedIn is clearly preferred.
3. **If he replies:** `henry_followup_teardown.md` → send as the promised one-page public-signal teardown.
4. **If he asks about background:** `portfolio_positioning.md` → use the proof stack and resume bullets.
5. **If he challenges fit:** `objection_handling.md` → answer only the objection he raises, then redirect to a concrete shipping offer.
6. **If he wants a trial:** use the 48-hour work-trial plan inside `flysoar_dossier.md`.
7. **If asked for sources:** `sources.md` documents the public and local evidence, including caveats.

## Do not send everything at once

The strongest sequence is:

```text
short DM → one-page teardown → 48-hour work-trial offer → portfolio proof stack
```

Sending the full dossier first would likely be too much. The dossier is for preparation; the teardown and short messages are for outreach.
