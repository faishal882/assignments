# Incident Room

A dependency-free, browser-based mock interview for Emergent’s production-debugging technical round.

## Run it

Open `index.html` directly, or serve the directory:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

The app includes six timed production scenarios, progressive evidence, private browser-persisted notes, model investigation paths, customer-safe status updates, and a 20-point self-scoring rubric.

Read [PREP_GUIDE.md](PREP_GUIDE.md) before the first full simulation.
